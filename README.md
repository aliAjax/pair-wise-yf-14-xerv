# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

给剧场灯光师使用的灯位与 Cue 表管理前端：维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和 Cue 触发顺序，包含舞台平面灯位图、Cue 列表、当前场景预览、灯具筛选和演出版本备注，适合排练期间快速调整。

## 巡台单与待确认流程

排练中临时停灯检修时的完整闭环：

- **暗场发巡台单**：登记灯具、预计恢复时间、值班师傅与检修原因；同一灯具同时只允许一张进行中的单。
- **触发拦截**：触发 Cue 时若触及尚未恢复的灯具，该 Cue 先停在「待确认」，并标明是哪盏灯、哪张巡台单、还剩多久。
- **签字放行一次**：师傅处理后签字，本次触发可放行执行；放行仅生效这一次，下次触发仍按当时的恢复情况重新判断。
- **维修延长**：工单延长后，等在确认里的 Cue 会按新的预计恢复时间重新显示延迟；已签的字自动作废，需师傅重新签字，不能沿用旧签字。
- **恢复**：工单标记已恢复后，被拦的 Cue 可直接执行；执行前会按当时的恢复情况再判断一次。
- **标记不可用**：舞台灯位图（红圈闪烁 + 「检」字）、灯具筛选（可只看检修中）、场景预览都会标出暂时不能用的灯。
- **持久化**：巡台单、待确认队列、场景与日志均存入 localStorage，页面重开后记录仍在。
